Audio and phone

The mic option sends the phone’s microphone to this computer. scrcpy can’t send your computer’s mic to the phone.

Keyboard

Click the phone to capture the keyboard. Game keyboard sends keys like a physical keyboard (WASD, arrows, Shift…); use right-click for Back. Video settings apply on the next connect.

Connection

On the phone, tick “Always allow from this computer” when asked. If the phone ever stops asking, reset the trust key and connect again.

Shortcuts

    Right-click is Back and middle-click is Home. In game keyboard mode only Alt/Meta shortcuts stay active, so games get every other key.
